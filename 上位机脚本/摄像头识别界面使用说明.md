# 摄像头识别界面

部署路径：`/home/jetson/classic/scripts/open_vision.sh`。

等当前抓取和回 HOME 完成后，在 **Jetson 桌面或远程桌面的终端**运行：

```bash
~/classic/scripts/open_vision.sh
```

脚本自动停止原先运行的 `huatai-vision.service`，加载虚拟环境并打开识别窗口。
需要时输入 Jetson 登录密码。窗口打开后，先松开 PE2，再按一次启动识别和抓取。

只看识别画面、不发送机械指令：

```bash
~/classic/scripts/open_vision.sh --preview
```

在画面窗口按 `q` / `Esc`，或在终端按 `Ctrl+C` 退出。
脚本先结束窗口程序，再自动恢复原先运行的后台服务；恢复后须重新松开、按下 PE2。
如果后台服务原本未运行，退出后仍保持停止。

不要用 `sudo` 启动整个脚本。没有图形显示环境或无法连接显示器时，脚本直接报错，
不会停止后台服务。普通 SSH 需要启用 X11 转发才能在电脑上显示窗口。

## 四点 ROI

在识别窗口按 `R`，沿托盘边缘顺时针或逆时针依次点击四个角。
四点会依次连线，第四点完成后自动闭合；按 `Enter` 或空格确认并保存。

- 右键或退格：撤回上一个点。
- `R`：清空本次选点。
- `Esc` / `Q` 或关闭选点窗口：取消，保留原 ROI。

四边形必须是按边缘顺序点击的凸四边形；交叉、重复或过小的选区无法保存。
抓取及回 HOME 途中不能打开选点窗口，动作完成后再按 `R`。
选点期间继续服务串口心跳，暂停选择抓取目标。

配置保存在 `/home/jetson/classic/config/roi.json`，重启后自动加载。
旧矩形配置仍可使用，新框选保存四个顶点及归一化坐标，分辨率变化时按比例缩放。
四边形外区域不参与颜色统计，抓取中心也必须位于四边形内。
原像素到机械坐标的标定关系不变。

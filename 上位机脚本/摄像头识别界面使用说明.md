# 摄像头识别界面

部署路径：`/home/jetson/classic/scripts/open_vision.sh`。

等当前抓取和回 HOME 完成后，在 **Jetson 桌面或远程桌面的终端**运行：

```bash
~/classic/scripts/open_vision.sh
```

脚本自动停止原先运行的 `huatai-vision.service`，加载虚拟环境并打开识别窗口。
需要时输入 Jetson 登录密码。窗口打开后，先松开 PE2，再按一次启动识别和抓取。

只看识别画面、不发送机械指令：

```bash
~/classic/scripts/open_vision.sh --preview
```

在画面窗口按 `q` / `Esc`，或在终端按 `Ctrl+C` 退出。
脚本先结束窗口程序，再自动恢复原先运行的后台服务；恢复后须重新松开、按下 PE2。
如果后台服务原本未运行，退出后仍保持停止。

不要用 `sudo` 启动整个脚本。没有图形显示环境或无法连接显示器时，脚本直接报错，
不会停止后台服务。普通 SSH 需要启用 X11 转发才能在电脑上显示窗口。

## 坐标发送优先级

每轮从有效目标中按以下顺序选择：五棱柱 → 长方体 → 正方体 → 圆柱 → 三棱锥 → 圆锥。
同类目标继续使用空旷度和移动距离评分。优先级在 `cv2_copy.py` 的
`PICK_SHAPE_PRIORITY` 中配置，数值越大越优先。

## 四点 ROI

在识别窗口按 `R`，沿托盘边缘顺时针或逆时针依次点击四个角。
四点会依次连线，第四点完成后自动闭合；按 `Enter` 或空格确认并保存。

- 右键或退格：撤回上一个点。
- `R`：清空本次选点。
- `Esc` / `Q` 或关闭选点窗口：取消，保留原 ROI。

四边形必须是按边缘顺序点击的凸四边形；交叉、重复或过小的选区无法保存。
抓取及回 HOME 途中不能打开选点窗口，动作完成后再按 `R`。
选点期间继续服务串口心跳，暂停选择抓取目标。

配置保存在 `/home/jetson/classic/config/roi.json`，重启后自动加载。
旧矩形配置仍可使用，新框选保存四个顶点及归一化坐标，分辨率变化时按比例缩放。
四边形外区域不参与颜色统计，抓取中心也必须位于四边形内。
原像素到机械坐标的标定关系不变。

## 机械坐标修正

编辑 Jetson 上的 `/home/jetson/classic/cv2_copy.py`，搜索 `MACHINE_X_OFFSET_MM`。
本地对应 `上位机脚本/cv2_copy.py`。仓库中的 `cv2_copy.py` 当前保留现场
X+7 mm、Y+8 mm 偏移（比例 1.0）：

```python
MACHINE_X_SCALE = 1.0
MACHINE_Y_SCALE = 1.0
MACHINE_X_OFFSET_MM = 7.0
MACHINE_Y_OFFSET_MM = 8
```

`classic-new/_cv2.py` 与 `上位机脚本/_cv2 copy.py` 仍为比例 1、偏移 0。
计算顺序为：像素标定转换 → 每轴乘比例、加偏移 → Y 上限限幅 → 目标筛选 → 串口发送。
例如希望机械 X 增加 3 mm、Y 减少 2 mm，可把两项 `OFFSET_MM` 改为 `3.0` 和 `-2.0`。
正负号以机械坐标方向为准。偏差随坐标大小变化时，可另调 `SCALE`；
例如 X 比例 `1.02`、偏移 `3.0` 会把标定 X=100 mm 修正为 105 mm。
这些是调参示例，修改后以启动日志打印的实际值为准。

识别界面显示、目标选择及下位机收到的抓取坐标都使用修正结果；
Y 超过 205 mm 时发送 205 mm，串口仍按原协议四舍五入为整数毫米。
主程序中修正后的 X 超过 0..215 mm 或 Y 小于 0 时不选择该目标。
修正只应用一次，ACK 超时重发沿用已经锁定的坐标。

修改后，等抓取及回 HOME 完成，在终端执行 `sudo systemctl restart huatai-vision.service`；
若使用前台识别窗口，则退出后重新打开。启动日志会打印实际生效的比例和偏移。
重启后先松开 PE2，再按一次开始识别。

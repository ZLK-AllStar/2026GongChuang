## 编码和累计计数

当前9形状×10颜色共90类，编码分三个区间，不能整体改为 shape*10+color+1：

```text
shape 0..7 / color 0..8: code = shape*9 + color + 1   (1..72)
shape 0..7 / color 9:    code = 73 + shape             (73..80)
shape 8 / color 0..9:    code = 81 + color             (81..90)
```

MCU `Core/Inc/hmi_codes.h` 和 HMI `src/hmi_codes.h` 为相同映射，回归核对字节一致。
HOST任务、DEBUG Shell和22字节生产帧D6均支持1..90；CRC、版本、帧长、ID六槽循环和任务去重不变。
圆锥各色分别累计同类总数，圆锥白色与球体白色等旧类分开；预览不计数、历史淘汰不减计数、新会话清零。

`HMI_SHAPE_CONE=8`。圆锥取料使用现有普通降杯深度；长方体的特殊全降规则不变。实际圆锥取料高度与吸取效果仍需上机验证。
视觉识别Python本轮未改，发送端须识别圆锥并按新增表发CMD。

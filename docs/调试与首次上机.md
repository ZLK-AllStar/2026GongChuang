# 调试与首次上机

2026-11-02 更新：DEBUG Shell 已切换至 PF2/PF4 软件串口；代码、离线模拟和 ARMCC 5 构建结果见 [软件串口验证记录](PF2-PF4软件串口Shell验证记录.md)。接线、电平、通信时序与机械验收尚未执行，本记录不代表已烧录。

## 接线与模式

软件串口：**PF2=TX 接 USB-TTL RXD，PF4=RX 接 USB-TTL TXD，GND 共地，3.3 V TTL**；终端设置 **4800/8N1、无流控、关闭本地回显**。先确认引脚到连接器导通、无板载器件争用；不接 RS-232 电平。UART5（PC12/PD2）已不再承载 Shell。不要将 Shell 文字送入 USART1 电机或 USART2 HOST。PE2 按键接 GND，内部上拉、低有效。PF9/PF10 分别 LED0/LED1，低电平亮。

TIM13 仅在 DEBUG Shell 初始化后启动，PSC=0、ARR=2187、8 倍采样，计算位宽约 208.381 μs（4798.903 baud）；HOST 无此定时中断负载。SysTick 继续提供应用毫秒时基。未调整 USART1/DMA 优先级或电机接收临界区；需在并发负载下测量后再决定是否优化。

复位后 LED0 快闪 3 秒，窗口内稳定按 PE2 20 ms 选择 DEBUG（LED1 亮），否则 HOST（LED0 亮）。HOST 初始化完成后先释放，再按 PE2 启动原视觉上位机。运行中按键不切换模式。无电机/初始化失败时 DEBUG 仍有 Shell，status 显示具体模块/阶段。

## 命令

一次输入一条，等待输出完成及提示符；512 字节编辑/历史缓冲由 Letter Shell 分成 6 份，每份 85 字节，单行最多 84 字节（不含终止符）。超长、RX 溢出、帧错误或采样失步会丢弃受损整行；提示后按 Enter，再重输。同步动作期间及跨动作边界的在途输入被丢弃，不会在数秒后连续执行粘贴命令。RX 环可用 255 字节，仅能缓存约 0.53 秒满速输入；不支持无限速批量粘贴。4800 baud 下 1 KiB 输出约需 2.13 秒，help/status 请耐心等候。

```text
help
status
move 1 0
move 0 0
move 0 1
move 0 0
move 1 1
lift up
lift down
lift full
lift 120
tray 60
tray 300
tray 0
vacuum on
vacuum off
hmi 1
hmi 72
hmi 73
hmi 80
hmi 81
hmi 90
zero xy
zero tray
```

| 命令 | 含义 |
|---|---|
| move x y | CoreXY 绝对 mm，X=0..215/Y=0..205；先抬杯，有效原点才运动 |
| lift up/down/full | 现有 240/80/10° 位置，等待 1000 ms 稳定；不移动 XY |
| lift angle | 绝对角度，十进制整数 0..270°，例如 `lift 120`；改变角度后等待 1000 ms，相同角度立即返回 |
| tray angle | 0..360° 固定单方向相位定位，360 等价 0；显示相位与累计角度 |
| vacuum on | 关释放阀，开泵并保持；不隐含升降或 XY |
| vacuum off | 停泵，等待 200 ms，开阀泄压 2000 ms，最终关阀 |
| hmi code | 十进制整数 1..90，一个原始字节，只预览，无生产 ID/记录 |
| zero xy/tray | 静止时将当前位置重建为软件原点，检查使能/清零应答及反馈；不是机械回零 |
| status | 缓存位置/目标/原点/真空/托盘/通信错误，无额外并行电机查询 |

`status` 末尾新增 `SOFTUART` 诊断：`rx/tx` 为完整接收/本地发送帧数（发送无对端确认），`frame` 为停止位错误、`false` 为假起始、`timing` 为节拍间隔/定时器相位超预算、`txfault` 为在途/队列发送被取消、`timeout` 为前台等队列超时。TX 短写也计入 `SHELL` 错误；Letter Shell 并非所有调用点都会重试，故障后的文本可能残缺，恢复后重新输入。发送失步时清待发队列、TX 保持至少一帧高电平后恢复；不会在故障路径递归打印。

`maxgap` 单位为 168 MHz CPU 周期，`maxlate` 为 84 MHz TIM13 tick；它们是诊断峰值，不能代替完整 ISR 耗时和事件到达前等待延迟的测量。正常负载 `timing/frame/txfault/timeout` 应保持 0；发现增长时记录数值与负载并按软件串口方案第 9 节排查。

`tray 0` 只定位零角相位，300→0 将继续转 60°；`zero tray` 将当前位置重新定义为零槽，清空累计角度。两者不可互换。

## 首次机械核对

1. 先核对 LED 极性、PE2 松开高/按下低和 PF2/PF4 软件串口接线；旧 PE4 不再控制启动。测试无按键、窗口内短按、上电长按及最后不足 20 ms 的边界抖动。用逻辑分析仪确认 TX 空闲高及位宽，并按软件串口方案进行长流量、全双工、异常恢复与最坏并发时延验收，再进行机械命令调试。二进制流测试须使用独立测试固件，不能向生产 Shell 灌随机字节。
2. 确认上电位置为预期 XY 原点和托盘第一槽零位；初始化只清软件位置，不主动运动。驱动地址 1/2/3、115200、16 细分必须核实。原点无效时先排查错误文本，不关闭校验强行放行。
3. DEBUG 中先用小位移 move 1 0、回零、move 0 1、回零、move 1 1 验证方向及比例，再逐步扩大。CoreXY 使用 2GT/20 齿/200 整步/16 细分=80 pulse/mm；M1/M2 正向宏初值协议 CCW=1，同时作用于反馈。按安装/观察面实测，不能按电机相同推断方向。必要时调整 XY_DEFAULT_RPM 后重建，不直接试满行程。
4. 核实托盘传动比初值 1.0 和方向；检查 0/60/120/180/240/300/0、0→300、120→60，确认不反转。一圈累计为 3200 pulse，容差初值 20 pulse（直连约 2.25°），需按槽口余量标定。
5. 独立验证 lift 和 vacuum，确认 TIM1 PE9/PE11 真空、TIM3 PA6 升降。保持当前抬杯释放策略；APP_RELEASE_X/Y_MM 初值 (0,0)，HOME 独立 (0,0)。先验证释放高度/位置再装料运行，未实测不改变原等待时间。
6. 指定 HMI 与 MCU 同步升级。hmi 1 / hmi 72 / hmi 73 / hmi 80 / hmi 81 / hmi 90 只预览（白色追加表见下位机白色几何体映射.md）；注入生产帧看 ID/图片，页面重开和超过 256 条淘汰不重新分配 ID。屏端真实串口/UI 仍需检查。
7. HOST 模式初始化后再按 PE2。抓串口确认 ACK 正常 <100 ms，整个循环 <20 s 且留余量，托盘在吸取前定位、原始坐标无旧偏移、固定 Release。连续七类对应 ID1..6/1，重复 A/F 保持 ID1/6。
8. 注入重复任务、越界、托盘断线、XY 反馈失败、HMI 断线，确认无重复动作/记录或假 DONE。取料后故障不得盲目泄压；停止命令在断线时可能送达失败，应通过硬件停机处理。

Shell 为同步前台，长动作中不解析新命令，不提供即时软件急停。DEBUG 不驱动 HOST，HOST 不执行 Shell。需即时打断控制时应另做非阻塞状态机，不能把当前串口命令当作急停。

最终参数与测试记录见机械架构变更验证记录.md；不自动烧录/部署。

## 2026-11-08 圆柱取料高度

圆柱系列全部十色（CMD 37..45、77）使用独立取料下降预设 130°，宏为 `AUX_SERVO_LIFT_DOWN_ANGLE_CYLINDER`。可在 DEBUG 下用 `lift 130` 验证高度，再抬杯；此预设由 HOST 按物料形状自动选择。130° 对应当前 TIM3 的 CCR=1462（1 us/tick），普通/FULL 预设当前为 100°。实际吸取接触高度与机械干涉仍需上机确认。

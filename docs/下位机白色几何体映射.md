## 联调与交付

DEBUG Shell 使用十进制 `hmi 73` 至 `hmi 80`，仅预览，不产生机械动作或生产记录。
串口助手使用 HEX 单字节 `49` 至 `50`，不要把十进制 73 输入为 HEX 73。

生成白色生产记录测试帧（不指定 --port 时不发送）：

```powershell
python -X utf8 tools/hmi_frame_test.py --record 73 1 --seq 1
python -X utf8 tools/hmi_frame_test.py --record 80 2 --seq 2
python -X utf8 tools/make_hmi_white.py
```

HMI 源码、8 张新 PNG、预览图与 CSV 已写入指定工程。ARM 库与 Windows 模拟器 DLL 编译通过后同步至该工程的 `Release/libbootpanel.so`、`Debug/libbootpanel.dll`；板端尚未部署。
升级屏端需同时打包库和 `images/*-WHITE.png`；MCU 也需更新固件以支持 HOST/Shell/记录的 73..80。
ApusIDE 中对工程执行 F5 刷新，再 Clean / Build，避免外部修改后复用旧对象。
